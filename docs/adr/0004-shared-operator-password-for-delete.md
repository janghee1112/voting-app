# 투표 삭제는 계정 없이 공유 운영자 비밀번호 하나로 보호한다

공개 주소로 배포된 뒤 로그인 없이 삭제 버튼을 두면 누구나 모든 투표를 지울 수 있다. 로그인·계정 시스템을 새로 만드는 대신, 서버 환경변수 `ADMIN_PASSWORD`에 둔 비밀번호 하나를 삭제 요청마다 함께 보내게 했다(세션·쿠키 없음). 비밀번호를 아는 사람은 모두 같은 운영자로 취급되고 누가 지웠는지는 남지 않는다. ADR-0001(로그인 없음)은 투표·만들기에는 그대로 유지되며, 이 결정은 삭제에만 예외를 둔다.

## Consequences

- `ADMIN_PASSWORD`가 설정되지 않은 환경에서는 삭제가 항상 거부된다(비밀번호 없는 삭제로 열리지 않게).
- 삭제하면 선택지와 득표수도 함께 사라진다(`on delete cascade`). 되돌릴 수 없다.
