# 마감 판정은 DB 시각(now())으로, 표를 올리는 같은 SQL 문장 안에서 한다

마감 시간 기능을 추가하면서, 마감 여부를 브라우저 시계나 API 코드의 `Date.now()`가 아니라 Postgres의 `now()`로 판정하고, 득표수를 올리는 `update` 문장의 조건(`closes_at is null or closes_at > now()`)에 함께 넣기로 했다. 화면에서 버튼을 비활성화하는 것은 안내일 뿐이고, 클라이언트 검증은 API를 직접 부르면 우회되기 때문이다. 한 문장 안에서 확인과 증가를 같이 하므로 "확인한 직후 마감되는" 경쟁 상태도 없다.

## Consequences

- `closes_at`은 nullable이며, 기존 투표(값 없음)는 무기한 열린 투표로 그대로 동작한다.
- 시각은 `timestamptz`(UTC)로 저장하고, 화면에는 한국 시간(Asia/Seoul)으로 보여준다. 생성 폼의 입력값은 브라우저가 자기 시간대로 해석해 ISO 문자열로 보낸다.
