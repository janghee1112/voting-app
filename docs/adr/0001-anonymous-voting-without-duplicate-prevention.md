# v1은 로그인·중복 투표 방지 없이 완전 익명으로 투표한다

동아리 회장의 요청 범위("질문을 올리면 사람들이 골라서 투표하고 결과를 본다")를 한 수업 안에 끝내기 위해, v1에는 투표자 로그인, 투표 생성자 권한, 중복 투표 방지(쿠키·IP 포함)를 넣지 않기로 했다. 같은 사람이 여러 번 투표할 수 있다는 것은 알고 받아들인 트레이드오프이며, 개별 표를 행으로 저장하지 않고 선택지의 득표수만 올리기 때문에 나중에 중복 방지를 붙이려면 표(votes) 테이블을 새로 추가해야 한다.

## Consequences

- 결과를 신뢰해야 하는 실제 선거에는 v1을 쓰면 안 된다.
- 중복 방지·마감 시간·결과 그래프는 부록 실습(기능 추가)에서 이 결정을 다시 열고 다룬다.
