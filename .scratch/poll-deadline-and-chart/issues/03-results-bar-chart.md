# 03: 결과를 퍼센트 막대그래프로

**What to build:** 결과 화면이 선택지별 퍼센트 막대그래프(득표수·퍼센트 숫자 포함)와 총 투표 수를 보여주고, 1등 선택지를 강조한다. 표가 0개면 "아직 투표가 없어요"와 0% 막대가 보인다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 막대 길이가 퍼센트와 같다
- [x] 1등(동률이면 모두)이 강조된다, 0표일 때는 강조 없음
- [x] 0표일 때 안내 문구, 에러 없음
- [x] 마감된 투표면 결과 화면에 "마감됨" 표시
