# 02: 투표하기

**What to build:** 투표자가 `/polls/[id]`에서 질문과 선택지를 입력 순서대로 보고, 하나를 골라 제출하면 해당 선택지의 득표수가 1 오르고 결과 화면으로 이동한다.

**Blocked by:** 01 (DB 스키마 + 투표 만들기)

**Status:** ready-for-agent

- [ ] 투표 조회가 질문·선택지(입력 순서)·득표수를 돌려주고, 없거나 잘못된 id면 "없음"
- [ ] 표를 던지면 득표수가 정확히 1 오르고, 동시에 여러 표가 와도 빠짐없이 세어진다
- [ ] 다른 투표의 선택지 id나 없는 id로는 표가 들어가지 않는다
- [ ] `GET /api/polls/[id]` 200/404, `POST /api/polls/[id]/vote` 200/400/404
- [ ] 선택 없이 제출 불가, 실패 시 에러 표시, 성공 시 `/polls/[id]/results`로 이동
- [ ] 없는 투표 주소는 404 화면
