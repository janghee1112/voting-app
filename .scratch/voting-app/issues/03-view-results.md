# 03: 결과 보기

**What to build:** 누구나 `/polls/[id]/results`에서 선택지별 득표수와 비율(%), 총 투표 수를 숫자 목록으로 본다(그래프 없음). 투표하기 화면에서도 결과 보기 링크로 갈 수 있다.

**Blocked by:** 02 (투표하기)

**Status:** ready-for-agent

- [ ] 선택지별 득표수와 정수 반올림 비율, 총 투표 수를 입력 순서대로 보여준다
- [ ] 표가 0개면 모든 선택지가 0표·0%
- [ ] 없는 투표면 404 화면
- [ ] 결과 화면에서 투표하기·목록으로 돌아가는 링크가 있다
